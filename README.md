# README

In this activity, you will practice writing basic Javascript syntax to clarify your understanding of Javascript is written and how you can manipulate the DOM with it. The starter code is in a github repo that you will clone to your computer (or fork and clone). Follow the hints in the code comments.

### Syntax Notes

- use camelCase instead of snake_case

### Answer Key

- Review the "spoilers" branch for examples of how these could be accomplished (note that in javascript there are many ways to do the same thing, the examples provided reflect secure and modern patterns.)

## Objectives

- Open the repository into vscode (or your editor of choice) and briefly walk through the files
- Connect the javascript file to the html file in the head or body
- Render a string of text from javascript into the h1 of the html file (using the most secure method)
- Create an array of your favourite characters, shows, teams (whatever you're into) and render it to the DOM
- Render a fake user name and email stored in a javascript object
- Use .classList to change the background colour of the user card
- Create a boolean variable to show if a user is logged in or not with a function that toggles the variable
- Create a conditional statement that updates the DOM based on the boolean value (false should empty the text fields and change the background colour
- Create an eventListener that will update the DOM when clicked so that the user-card information is updated

## Task Details

1. Connect JavaScript to HTML:
   - Open `index.html`
   - Add a `<script>` tag to include your `script.js` file.

2. Render Text to h1:
   - In `script.js`, use the most secure method to render a string of text to the h1 element in `index.html`.
   - Target the h1 element using its ID or another appropriate selector.

3. Create and Render an Array:
   - Create an array containing your favorite characters, shows, teams, or other items.
   - Render this array to the DOM in a meaningful way (e.g., as a list).

4. Create and Render a User Object:
   - Create a JavaScript object with properties for a fake user name and email.
   - Render this information to the DOM in a user card.

5. Change Background Color:
   - Use `.classList` to change the background color of the user card.

6. Toggle Login Status:
   - Create a boolean variable to track the login status.
   - Create a function that toggles this boolean variable.

7. Conditional DOM Update:
   - Create a conditional statement that updates the DOM based on the boolean value.
   - When the boolean is false, empty the text fields and change the background color.

8. Event Listener for Updates:
   - Create an event listener that triggers when a specific element is clicked.
   - Update the DOM with new user-card information when the event is triggered.
